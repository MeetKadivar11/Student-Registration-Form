# Student Registration Form

A simple and responsive Student Registration Form created using HTML and CSS.

## 📌 Project Overview

This project is a basic student registration form designed to collect student information through a clean and user-friendly interface.

## ✨ Features

- Student name input
- Email input
- Mobile number input
- Date of birth selection
- Gender selection
- Branch selection
- Semester selection
- Subject selection using checkboxes
- Address textarea
- Submit and Reset buttons
- Styled using CSS

## 🛠️ Technologies Used

- HTML5
- CSS3
